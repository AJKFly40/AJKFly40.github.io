Waiting for the drawing.

Your device asks for reduced motion, so the balls do not tumble — the drum is still and each ball is simply marked as it is drawn. The drawing runs at exactly the same pace as everybody else’s, so you stay with the room, and every line of commentary is printed above.

    What stops this being rigged

    Two separate commitments. The assignment above — who owns which combinations — was written and fingerprinted days before tonight, so the numbers cannot be handed out after somebody has seen the balls. The result is not pre-committed at all, because it does not exist until it is drawn in front of the league; its fingerprint is computed by your own browser from the file it receives, so every viewer can read out the same hash and compare.
